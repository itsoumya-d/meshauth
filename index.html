How It Works

1. Client Initiation

App requests authentication via MeshAuth SDK.

2. WebAuthn Handshake

Browser prompts user for biometrics (Passkey, FaceID, Windows Hello).

3. Cryptographic Verification

MeshAuth backend verifies the public key signature natively.

4. Secure Session

JWT is issued. Zero passwords stored, zero breaches possible.

Frequently Asked Questions

Is MeshAuth a completely free alternative to Clerk?

Yes. MeshAuth is an open-source library that you host yourself. You only pay for your own basic infrastructure, eliminating per-user MAU pricing entirely.

Does it support traditional passwords?

No. MeshAuth is strictly a zero password WebAuthn client. We believe passwords are an outdated security risk. Passkeys are the future.

Can I migrate from Firebase Auth or Auth0?

Absolutely. Since MeshAuth validates standard JWTs, you can easily swap out your Auth0/Firebase verification middleware with MeshAuth's.
